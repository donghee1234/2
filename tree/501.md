순차 탐색 vs 이진 탐색 트리(BST) 탐색 비교
측정 결과
항목	값
BST 생성 비용 (총 비교 횟수)	810회
순차 탐색 50회 총/평균 비교 횟수	4,728회 / 94.56회
BST 탐색 50회 총/평균 비교 횟수	494회 / 9.88회
분석
성능 차이: BST 탐색이 순차 탐색보다 평균 비교 횟수가 약 9.6배 적다. 순차 탐색은 데이터 전체를 확인할 수 있어 O(n), BST는 한 번 비교할 때마다 탐색 범위가 절반씩 줄어 O(log n)이기 때문이다.
생성 비용 포함 시: BST 생성(810회) + BST 탐색(494회) = 1,304회로, 여전히 순차 탐색(4,728회)보다 적다. 다만 탐색을 적게 할수록 생성 비용 부담이 커지므로, BST는 반복 탐색이 많을수록 유리하다.
트리 구조의 영향: 데이터가 무작위 순서로 삽입되면 트리가 균형에 가까워 탐색이 빠르지만, 오름차순/내림차순에 가깝게 삽입되면 편향 트리가 되어 최악의 경우 순차 탐색과 비슷한 수준(최대 100회)까지 느려질 수 있다.
결론

같은 데이터를 여러 번 탐색할 경우 생성 비용을 포함해도 BST 탐색이 순차 탐색보다 효율적이다. 이 이점은 트리가 균형 잡힌 모양일 때 유효하다.
